Support

Help for CurDeepSeek — a DeepSeek-native Windows AI coding environment (folder workspace, agent, diffs, terminal, Git). This page is intended as the Microsoft Store support / contact URL once hosted on public HTTPS.

Before you contact us

  • Confirm a DeepSeek API key is set under Settings → API (stored locally in Windows Credential Manager).
  • Note your app version (Settings → About) and Windows edition (x64 / ARM64).
  • Use Settings → About → Export diagnostics if you need a local zip for troubleshooting (secrets are scrubbed from text; dumps stay local unless you share them).

Common topics

  • API / AI features — Chat, agent, Composer, and Ctrl+K require a valid DeepSeek API key and network access to the configured API host.
  • Permissions — Destructive or remote git/shell actions may prompt; default is deny without an allowlist entry.
  • Updates — Microsoft Store builds update through the Store. Sideload / lab HTTPS feeds are a separate channel and are not the Store support path.
  • Privacy — See the privacy policy (local key, no invented telemetry).
