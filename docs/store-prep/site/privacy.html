Privacy Policy

This page describes how CurDeepSeek handles data on your device and what leaves your machine when you use AI features. It matches the Microsoft Store listing claims for the product.

Summary

  • Your DeepSeek API key is stored locally in Windows Credential Manager on your PC.
  • App settings, chat history, and related state live in a local SQLite database under your user profile.
  • CurDeepSeek does not run invented product telemetry or upload crash dumps by default.
  • When you use chat, agent, Composer, or inline AI, prompts and completions are sent to the DeepSeek API (or the API base URL you configure).

Data stored on your device

  • API key — Windows Credential Manager entry for CurDeepSeek / DeepSeek (local only).
  • Settings & sessions — SQLite under %LOCALAPPDATA%\CurDeepSeek (preferences, recent workspaces, chat turns, agent run metadata, permissions allowlists, etc.).
  • Optional crash dumps — local files under %LOCALAPPDATA%\CurDeepSeek\dumps for diagnostics; not uploaded by the app.
  • Workspace files — edited only in folders you open; the app does not host a CurDeepSeek cloud account.

Data that leaves your device

  • DeepSeek API — When AI features are used, request content (prompts, relevant context you allow the agent/tools to send) and model responses go to DeepSeek over HTTPS. Treat that traffic under DeepSeek’s own terms and privacy policy.
  • Optional update checks — Non-Store / sideload builds may check an HTTPS update feed you configure (or the default lab feed). That is separate from Microsoft Store update distribution.
  • Optional MCP servers — If you configure Model Context Protocol servers, those connections use the endpoints you choose; CurDeepSeek does not invent a telemetry backend for them.

What we do not claim

  • No CurDeepSeek-operated analytics / telemetry pipeline is part of the default product behavior described in the Store listing.
  • Crash dumps and Export Diagnostics stay local unless you explicitly export and share them.
  • There is no CurDeepSeek cloud account; the optional credential is your DeepSeek API key on this machine.

Deleting local data

Close the app, then remove %LOCALAPPDATA%\CurDeepSeek (and clear the Windows Credential Manager entry for the DeepSeek API key if you want the key gone). Revoke or rotate the API key at your DeepSeek provider dashboard if it may have been exposed.

Children

CurDeepSeek is a developer productivity tool. It is not directed at children. See the Store age rating questionnaire answers for market-specific ratings.
